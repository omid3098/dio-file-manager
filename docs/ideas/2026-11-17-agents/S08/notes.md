# Ghost names

Six unclear names are preselected in Downloads. “Name by content” simulates the user's Codex reading screenshots, PDFs, a photo and an archive; editable grey names appear under the originals, including a Persian suggestion. Tab or Enter renames the batch, Undo restores it, Esc discards it, and View Options can hide the offer.

## Deliberate limits

This is an HTML sample. Agent reading and filesystem changes are simulated; no files are read or renamed. The initial selection is supplied so the feature's button is visible in the gallery. The opt-out is stored locally, but opening or restarting this demonstration resets it to let the next viewer try the feature. No actual agent connection or language translation is performed.
