# Agent feature ideas Omid liked, 2026-11-17

From a second idea round of 21 features that let users put their own AI agent (Claude Code, Codex, Gemini CLI or a local model) to work inside the file manager. Several AI models gave ideas blind; one maker built a clickable mock of each. Omid liked these four on 2026-11-17. Not built yet.

Open a mock: `SXX/index.html` in a browser, from this folder (no server needed). The Persian strip above the window says what to do, and an indigo ring marks the next thing to click.

## Why is this here (S04, «این اینجا چی‌کار می‌کنه؟»)

یه فایل یا پوشه‌ای که نمی‌شناسی رو انتخاب کن؛ ایجنت تو یه خط می‌گه کی ساختتش، هنوز به کار میاد یا نه، و پاک کردنش امنه یا نه.

- Omid: «این ایدهٔ جالبیه واسه وقتی که فضای دیسک کم باشه.»
- Mock: [S04/index.html](S04/index.html)

## About lines (S06, «یه خط زیر هر اسم»)

وقتی پشت هم فایل باز می‌کنی دنبال یه چیز، پیشنهاد می‌ده ایجنت همه رو بخونه و زیر هر اسم یه خط بنویسه که چیه.

- Omid: «ایدهٔ خوبیه که نشون بده کدوم فایل به چه دردی میخوره. سوال اینه که این دیتا کجا نگهداری بشه؟»
- Open: where the lines are stored (see the answer given to Omid in the session; not decided yet).
- Mock: [S06/index.html](S06/index.html)

## Ghost names (S08, «اسم‌های پیشنهادی کم‌رنگ») and Names from contents (S19, «اسم از توی فایل»)

S08: چندتا فایل با اسم بی‌معنی رو انتخاب کن؛ ایجنت توشون رو می‌خونه و زیر هر اسم یه اسم بهتر کم‌رنگ می‌نویسه، با Tab همه رو قبول می‌کنی.

S19: روی یه فایل با اسم ماشینی F2 بزن؛ کادر تغییر اسم از قبل یه اسم کم‌رنگ داره که ایجنت از توی فایل خونده، Tab قبولش می‌کنه.

- Omid: «۸ و ۱۹ هم جالبه برای تغییر اسم فایلها. به اونی نیاز داریم که کاربر کار دستی کمتری انجام بده.»
