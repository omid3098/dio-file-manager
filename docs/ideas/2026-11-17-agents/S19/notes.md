# Names from contents

The grey name lives inside F2's rename field; Tab accepts it and Enter commits it. Typing discards it. Machine-named scans also open editable English/Persian batch proposals, with Undo. The small Tab menu stops suggestions; restarting resets the whole demo.

## Limits

Reading contents and inferring folder style are simulated with fixed examples, as this is a browser sample. The opening view starts just after F2 so the gallery already shows the idea; F2 works on selected files afterwards. No real files or agents are used.
