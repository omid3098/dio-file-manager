# Feature ideas Omid picked, 2026-11-17

From an idea round of 21 new features (several AI models gave ideas blind; one maker built a clickable mock of each). Omid picked these four on 2026-11-17 and asked to keep them («این ایده‌ها رو نگهدار»). Not built yet.

Open a mock: `SXX/index.html` in a browser, from this folder (no server needed). The Persian strip above the window says what to click.

## Fresh Trail (S03, «ردِ تازه»)

یه جای تازه توی سایدبار به اسم «Just Made» که فایل‌هایی که همین الان یه جا ساخته شدن رو دسته‌دسته نشون می‌ده، و هر دسته رو با یه کلید می‌شه انداخت توی سطل.

- For Omid: معلوم می‌شه کدوم ایجنت کدوم worktree رو پر از لاگ و اسکرین‌شات کرده، و با یه Delete جمعش می‌کنی.
- For anyone: بعد از یه نصب یا باز کردن یه zip، می‌بینی همه‌چی کجا ریخته شده و می‌تونی یه‌جا پاکش کنی.
- Mock: [S03/index.html](S03/index.html)

## Either Keyboard Search (S13, «جستجو با کیبورد اشتباهی»)

اگه اسم فایل رو با کیبورد انگلیسی تایپ کنی ولی منظورت فارسی بوده، مثلاً rhvnhn به جای «قرارداد»، جستجو باز هم پیداش می‌کنه.

- For Omid: اسم‌های فارسی و انگلیسی کنار هم‌اند و کیبوردت معمولاً روی انگلیسیه؛ مدرک رو بار اول پیدا می‌کنی.
- For anyone: هر کسی با دو زبان روی ویندوز، مثل روسی یا عربی کنار انگلیسی، همین کمک رو بدون تنظیم می‌گیره.
- Mock: [S13/index.html](S13/index.html)

## Blink Compare (S19, «مقایسهٔ چشمکی»)

دو تا عکس رو انتخاب کن تا روی هم بیفتن؛ با نگه داشتن Space بینشون چشمک بزنی یا با یه خط وسط بکشی و ببینی دقیقاً چی عوض شده.

- For Omid: فرق دو نسخهٔ تکسچر یا رندر رو چند ثانیه‌ای می‌بینی، بدون باز کردن دو تا برنامهٔ عکس کنار هم.
- For anyone: دو تا عکس یا دو تا اسکن رو مقایسه می‌کنی تا قبل از پاک کردن، بهتره رو نگه داری.
- Mock: [S19/index.html](S19/index.html)

## What Grew This Week (S21, «این هفته چی بزرگ شد»)

نوار پر بودن هر درایو نشون می‌ده این هفته چقدر بهش اضافه شده، و یه کلیک می‌گه کدوم پوشه‌ها بزرگ شدن.

- For Omid: درایو C کوچیکه و قبلاً پر شده؛ اینجا وقتی هنوز چند گیگه می‌بینی چی داره پرش می‌کنه.
- For anyone: هر کسی که لپ‌تاپش داره پر می‌شه، می‌فهمه کدوم پوشه بزرگ شده، نه فقط کدوم بزرگه.
